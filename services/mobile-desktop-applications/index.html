When this is the right form

When the task has to be completed away from a desk, or on a screen the current product does not serve. The first question is whether the same task can be delivered through a responsive browser application; that answers most requirements without a separate native build.

What the work can include

  • Responsive browser-based interfaces
  • Device and user context review
  • Application workflow planning
  • Interface design for common screen sizes
  • Native application requirements assessment

What it depends on

Many business tasks can be handled through a responsive web application. If native software is required, the approach and scope are assessed before a commitment. Device support, offline behaviour, and store distribution are confirmed rather than assumed.

Evidence

SAD builds websites and browser-based tools. Native mobile or desktop work is assessed brief by brief: what is feasible and how it would be delivered are confirmed before any commitment.

No native app release is claimed. The relevant evidence is the responsive work already live on this site and in client projects.
